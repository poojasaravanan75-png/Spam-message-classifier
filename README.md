# Spam Message Classifier

ML-based SMS spam classifier using Naive Bayes and TF-IDF vectorization.

## Overview
Built an end-to-end machine learning pipeline to classify SMS messages as spam or ham (legitimate), achieving 97.85% accuracy on test data.

## Tech Stack
- Python, scikit-learn, pandas
- TF-IDF Vectorization
- Multinomial Naive Bayes

## Dataset
SMS Spam Collection Dataset (5,572 labeled messages)

## Results
- Accuracy: 97.85%
- Precision (spam): 100%
- Recall (spam): 84%

## How it works
1. Text preprocessing using TF-IDF vectorization
2. Train-test split (80-20)
3. Naive Bayes classification
4. Interactive prediction function for live testing
